# User guide
**First run:** Settings → enable a source (server URL + token, or M3U URLs) → *Save & sync now*. The library fills from real data only.
**Mobile:** bottom bar (Home, Movies, Series, Search, Library), gear icon for Settings. Tap a card for details; series show seasons/episodes.
**TV:** use the D-pad. Left/right moves along rows, up/down between rows and the top tab bar; OK selects; Back returns. Search uses the on-screen keyboard.
**Playback:** "Watch Now/Resume" plays authorised streams in-app (gear icon in the player for audio/subtitles). Next episode starts automatically.
**Watchlist/Continue Watching/Backup:** stored locally. Backup export/import is in mobile Settings.
