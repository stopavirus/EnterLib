# Troubleshooting
- **Empty library:** enable a source and sync; check Settings → Sync history for the error text.
- **Sync "HTTP 401":** wrong token. **Cannot connect:** use the server's LAN IP and port; same network.
- **Playback error:** the container/codec may be unsupported for direct streaming; try another title or an HLS playlist.
- **TV focus lost after returning from details:** known limitation; focus restoration is basic.
- **Background sync late:** Android battery optimisation; use Manual sync.
- **CI failure:** open the failed step; fix the first compiler error shown (first build was never compiled before delivery).
